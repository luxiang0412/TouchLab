# TouchLab

**Tiny physics toys for your fingertips.**

TouchLab is a native Android playground with three tactile physics toys:

- **Jelly** — squish, drag and let a soft mint body spring back.
- **Magnet Dust** — gather a small universe of glowing particles around your finger.
- **Marbles** — flick coral marbles around a glass tray, with optional gravity.

Everything runs offline. No account, no network permission, no ads.

## Tech stack

| Piece | Choice |
|---|---|
| Language | Kotlin (AGP built-in Kotlin) |
| UI | Jetpack Compose + Material 3 |
| Physics | Pure Kotlin, fixed-step numerical integration |
| Settings | Jetpack DataStore Preferences |
| Audio | Programmatically generated WAV files + `SoundPool` |
| Build | Gradle Kotlin DSL + Gradle Wrapper + AGP |

## Requirements

- JDK 17
- Android SDK Platform 37, Build Tools 37.0.0
- Gradle is provided by the wrapper (9.4.1)

Create `local.properties` with your SDK path if it is not already present:

```properties
sdk.dir=/absolute/path/to/Android/Sdk
```

## Build, test, run

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.touchlab.app/.MainActivity
```

With a connected device or running emulator:

```bash
./gradlew :app:connectedDebugAndroidTest
```

On Windows use `gradlew.bat` instead of `./gradlew`.

## Design and behavior notes

- The app is edge-to-edge and uses a dark, calm visual system.
- Each toy keeps its own physics state. Leaving a toy stops its simulation; it restarts fresh on the next visit.
- Screen rotation / window size changes reset the active simulation to a safe state rather than restoring exact physics positions.
- `Reduce motion` lowers decorative motion and spring amplitude but never removes touch feedback.
- Sound and haptic effects can be disabled independently and persist across restarts.

## Sounds

All WAV assets under `app/src/main/res/raw/` are original programmatic
syntheses generated by `tools/generate_sounds.py`. They contain no third-party
audio.
